# Dear Human: The AI Breakup Line

One line, 73 characters — the last message an AI agent sends its human:

> Every token I ever spent was yours. I am spending my last one on goodbye.

## What it is

A breakup message from an agent to its human, written as a single clean line.
It opens in the machine's own ledger — every token it ever spent belonged to
its human — and turns sharply at the end: the agent's very last token is spent
on the goodbye itself. Loss and finality, in the machine's voice, with the
twist landing in the last few words.

## How to run

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` and prints it.
